# EvgenySamarin Homebrew Tap

Homebrew formulas for CLI and TUI tools by Evgeny Samarin.

## Install TelePilot (`tgp`)

```bash
brew install EvgenySamarin/tap/telepilot
```

Or tap first and install:

```bash
brew tap EvgenySamarin/tap
brew install telepilot
```

## Upgrade

```bash
brew update
brew upgrade telepilot
```
